1. Strongest supporting evidence

Eivind identifies the ten-seed result in Setting A. Q-learning succeeded in all 2,000 evaluation episodes (100.0 ± 0.0% across ten trained agents); PPO reached 99.4 ± 2.1%, with nine seeds at 100% and one at 93.5%. 3. A plausible alternative explanation

Eivind proposes that PPO's higher B success reflects the selected Q-learning configuration rather than an intrinsic algorithm advantage. On the matched training seeds 0–4, selected PPO scores 94.3%, selected Q-learning (α 0.3) 67.2%, and Q-learning with only α changed to 0.1 scores 86.4%. The PPO lead shrinks from 27.1 to 7.9 percentage points. All five Q pairs favour α 0.1; α 0.3 seeds 0 and 1 deteriorate in the last 100,000 steps.

He proposes retuning both agents on new tuning seeds, then evaluating new trained agents on fresh evaluation seeds. The current comparison demonstrates configuration sensitivity, not which algorithm is best tuned. Tuning seeds 100–102 favoured α 0.3 (83.7% versus 53.5%, with final ε 0.01 for both). Choosing α 0.1 now using evaluation results would violate comparison rule 7. A future study must keep selection separate from final assessment; crossing the descriptive pooled-SD threshold alone would not establish a causal explanation for a remaining gap.
